# Hosts 格式说明

DNS Override 支持导入标准 hosts 文件格式（与 `/etc/hosts` 兼容）。

## 格式

每行一条记录，字段以空格或 Tab 分隔：

```
<IP> <domain1> [domain2 ...]  # 可选注释
```

- IP 为 IPv4 或 IPv6
- 一行可指定多个域名共享同一 IP
- `#` 后的内容视为注释，会被忽略
- 空行被忽略

## 特殊 IP

- `0.0.0.0` 或 `127.0.0.1`：作为拦截（ad-block 风格），导入时 IP 保持原值
- 其他 IP：作为 DNS 重写，导入时直接 override

## 示例

```
# 屏蔽广告
0.0.0.0 ad.example.com
0.0.0.0 tracker.example.com

# 内网解析
192.168.1.100 myapp.local
192.168.1.101 api.myapp.local

# 一行多域名
10.0.0.1 a.test b.test c.test

# 行内注释
127.0.0.1 localhost  # 本地回环
```

## 导入方式

1. 进入「规则管理」页
2. 点右上角菜单 → 「导入 hosts」
3. 系统文件选择器打开，选择 hosts 文本文件
4. 选择「新建规则组」或「追加到当前组」
5. 导入后可编辑/启停单条规则

## 导出

导出时：
- 仅包含启用状态的规则，禁用规则被跳过
- 规则备注会作为行内注释保留
- 文件头部包含导出时间和规则组名
